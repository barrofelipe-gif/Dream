Como embutir vídeos do Instagram e do YouTube que "abrem" a rede original ao clicar

Os dois exemplos abaixo carregam o conteúdo direto do domínio original (instagram.com / youtube.com) dentro de um iframe. O vídeo em si nunca sai de lá — o seu site só "encaixa a janela". Clicar no post do Instagram ou no logo do YouTube leva o visitante pra rede social.

1. Instagram (embed oficial)

Pegue o link do post/reel → botão "..." → Incorporar (ou Embed) → copie o código. Ele sempre tem esse formato: 

<blockquote class="instagram-media"
  data-instgrm-permalink="https://www.instagram.com/p/SEU_POST/"
  data-instgrm-version="14">
</blockquote>

<script async src="//www.instagram.com/embed.js"></script>

2. YouTube (iframe padrão)

Mais simples: pegue o ID do vídeo na URL e monte o iframe.

<iframe
  width="100%" height="220"
  src="https://www.youtube.com/embed/ID_DO_VIDEO"
  frameborder="0" allowfullscreen>
</iframe>

Pontos importantes

  • O post/reel precisa ser público. Conta privada não embuta.
  • Cada blockquote do Instagram precisa do script embed.js na página. Se você tiver vários posts na mesma página, inclua o script uma única vez (não repita por card).
  • Se os posts forem carregados dinamicamente (ex: via JS, depois que a página já abriu), chame window.instgrm.Embeds.process() manualmente depois de inserir os novos blockquotes — é isso que faz o script reprocessar e transformar os blockquotes em iframe.
  • Isso é renderização client-side: o HTML original mostra só o blockquote (texto/link cru); o card bonito com o vídeo só aparece depois que o JS do Instagram roda no navegador do visitante. Bom pra evitar hospedar vídeo você mesmo; ruim pra SEO/carregamento se você abusar de muitos embeds na mesma página.
  • Existe também a oEmbed API oficial do Instagram (via Graph API), usada quando você quer gerar o HTML do embed programaticamente no seu backend (ex: o usuário só cola o link e o sistema busca o código pronto). Isso exige um app registrado no Facebook for Developers e um access token — só vale a pena se for gerar embeds em massa/automatizado. Pra colar 5-10 posts fixos no site, o blockquote manual acima já resolve.
