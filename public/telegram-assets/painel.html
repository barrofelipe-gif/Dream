Prepare o aplicativo BFF no Telegram

Você usa sua conta atual do Telegram. Antes do primeiro QR Code, o Telegram precisa identificar o aplicativo BFF com duas chaves: API ID e API Hash.

  1. Abra o site oficial abaixo, entre com o número que você já usa no Telegram e confirme o código recebido no aplicativo.
  2. Abra API development tools. Se aparecer um formulário de aplicativo, use os dados sugeridos abaixo.
  3. Copie o API ID e o API Hash para os campos deste painel. Depois clique em Conectar por QR Code.

Proteger minha comunidade

Ao aplicar, o sistema retira os endereços públicos do grupo, tenta ocultar a lista de membros e ativa a restrição de salvamento de conteúdo.

Os endereços públicos anteriores deixam de funcionar. Os membros atuais permanecem e podem continuar conversando, conforme as permissões do grupo. Convites existentes precisam ser revisados no Telegram.

Ocultar membros depende da disponibilidade liberada pelo Telegram. O painel confere o resultado de cada proteção.
